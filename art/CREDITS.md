# Prop models

Source scene: `props.blend`. Pipeline: `bake_props.py` (run inside Blender) bakes each
model's colour into vertex colours — the game uses no textures — and exports
`unity/Pancing/Assets/Pancing/Resources/Models/*.fbx`.

All downloaded models are CC0 1.0 (public domain, no credit required) by Quaternius, via Poly Pizza.
